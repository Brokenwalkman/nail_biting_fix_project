This fun personal project was born out of a very annoying problem that I face - Nailbiting. It's not as optimised as it could be but it is meant to more so potray an MVP of the idea. The main folder with all the files has the correct, most up to date code . This project primarily uses google's mediapipe framework and tasks API along with open CV for its computer vision processes. You can also play around and record funny sounds to keep you from your nailbiting habit and replace the winsound.beep line in the mail loop with your own audio clip using a different function ! Just click on run all and make sure your laptop camera is not obstructed by a physical shutter. If you are using a separate camera, you might wanna change the camera selection in the open cv capture line. Any time you subconciously try to bite your nails, the program will let out a loud beep to let you to inform you and help you prevent it,
