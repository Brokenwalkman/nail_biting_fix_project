This fun personal project was born out of a need to fix a very annoying problem that I face - Nailbiting. The solution is meant to potray an MVP of the idea which essentially uses computer vision for specific behaviour prevention by playing a loud sound any time the user proceeds to bite their nails. The main folder with all the files has the correct, most up to date code. This project primarily uses google's mediapipe framework and tasks API along with open CV for its computer vision processes. You can also play around and record funny sounds to keep you from your nailbiting habit and replace the winsound.beep line in the mail loop with your own audio clip using a different function ! Just click on run all and make sure your laptop camera is not obstructed by a physical shutter. If you are using a separate camera, you might wanna change the camera selection in the open cv capture line.
