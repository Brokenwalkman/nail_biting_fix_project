This fun personal project was born out of a very annoying problem that I face - Nailbiting. It's not the most optimised it could be but is meant to look more so potray an MVP of the idea. The main folder with all the files has the correct, most up to date code . This project primarily uses google's mediapipe framework and tasks API along with open CV for its computer vision processes. You can also play around and record funny sounds to keep you from your nailbiting habit and replace the winsound.beep line in the mail loop with your own audio clip using a different function !
